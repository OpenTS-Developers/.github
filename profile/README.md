OpenTS is a community-led, open-source reconstruction of *Command & Conquer:
Tiberian Sun*: the original engine rebuilt standalone as a conventional C++
project, playable today.

- [OpenTS](https://github.com/OpenTS-Developers/OpenTS) — the active engine:
  source, releases, and issues
- [TibSun](https://github.com/OpenTS-Developers/TibSun) — the archived
  reconstruction baseline
- [Manual](https://opents-developers.github.io/OpenTS/) — INI configuration,
  mapping, and engine internals
- [Discord](https://opents.net/discord)

OpenTS is an independent community project and is not affiliated with or
endorsed by Electronic Arts.
